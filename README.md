# 🌍 WanderVista – Holiday Packages Website

WanderVista is a modern and responsive **Holiday Packages website** built with **React.js**. It allows users to explore travel packages, search for destinations, view package details, and submit travel enquiries.

## ✨ Features

* 🏝️ Explore different holiday packages
* 🔍 Search packages by destination, type, or package name
* 📦 Dynamic package cards
* 👀 View package details in a popup
* 📝 Travel enquiry form
* 📱 Fully responsive design
* 🎨 Clean and modern UI
* ⚡ Built with React components
* 🌐 Package data displayed dynamically

## 🛠️ Technologies Used

* React.js
* JavaScript
* HTML5
* CSS3
* React Hooks
* Vite
* Git & GitHub

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/anmolbhatia-15/holiday-packages.git
```

### 2. Go to the project folder

```bash
cd holiday-packages
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The project will run on your local development server.

## 🔍 Search Feature

Users can search for destinations such as:

* Goa
* Bali
* Manali
* Mountains

The package cards update according to the search input.

## 📦 Package Details

Each package contains information such as:

* Package name
* Destination
* Package type
* Price
* Description
* Image

Users can click **View Details** to see more information about a selected package.

## 📋 Travel Enquiry

The website also includes a travel enquiry form where users can provide:

* Full Name
* Email
* Phone
* Travel Date
* Selected Package
* Number of Travellers

## 📱 Responsive Design

The website is designed to work across:

* 💻 Desktop
* 📱 Mobile
* 📲 Tablet
